# 🏛️ سامانه جامع و یکپارچه CRM و مدیریت فروش فرش (Persian Carpet CRM)

> **یک محصول نرم‌افزاری واقعی، تجاری و تحت وب (Production-Grade Responsive Web CRM) مهندسی‌شده به صورت کاملاً فارسی و راست‌چین (RTL-First) ویژه کارخانجات، بازرگانان و فروشگاه‌های زنجیره‌ای فرش دستباف و ماشینی ایران.**

---

## 💎 ویژگی‌های کلیدی سامانه

### ۱. معماری بومی فارسی و راست‌چین (Persian-First & 100% RTL)
- **پشتیبانی کامل از `dir="rtl"` و `lang="fa"`** با تایپوگرافی اختصاصی و استاندارد **وزیرمتن (Vazirmatn)**.
- **تبدیل و نمایش استاندارد ارقام فارسی (`۰۱۲۳۴۵۶۷۸۹`)** در تمامی قیمت‌ها، متراژها، شانه، تراکم، کد انبار و شماره فاکتورها.
- **محاسبه و نمایش مبالغ به تومان** با جداسازی سه‌رقمی فارسی.
- **تقویم تمام جلالی (شمسی)** در تمامی تاریخ‌های پیگیری، سررسید چک‌ها، فاکتورها و گزارش‌های تحلیلی.
- **اعتبارسنجی و نرمال‌سازی شماره‌های همراه ایران** (`۰۹۱۲۳۴۵۶۷۸۹`).

### ۲. پروفایل نیازسنجی تخصصی فرش (Carpet Need Profile)
- ثبت و تحلیل دقیق ابعاد (`۲×۳`، `۲.۵×۳.۵`، `۳×۴`، `۱.۵×۲.۲۵`، `قالیچه`، `کناره`).
- شانه (`۷۰۰`، `۱۰۰۰`، `۱۲۰۰`، `۱۵۰۰`) و تراکم (`۲۵۵۰` تا `۴۵۰۰`).
- سبک نقشه (`کلاسیک`، `نئوکلاسیک`، `مدرن طلاکوب`، `وینتیج`، `عشایری و خشتی`).
- تم رنگی، متراژ فضا، سقف بودجه، اولویت نقدی یا اقساطی.

### ۳. موتور هوشمند امتیازدهی لیدها (Rule-Based Lead Scoring)
- استعلام قیمت: `+۱۰` | درخواست تصویر/کاتالوگ: `+۵` | انتخاب طرح مشخص: `+۱۵` | استعلام شرایط اقساط: `+۱۵` | اعلام بودجه مشخص: `+۱۰` | درخواست ارسال/پرو در منزل: `+۲۰` | عدم پاسخ به پیگیری: `-۱۰`.
- دسته‌بندی خودکار به دماهای **داغ (Hot)**، **گرم (Warm)**، **سرد (Cold)** و ضعیف.

### ۴. پایپ‌لاین فروش بصری با درگ اند دراپ (Kanban Pipeline)
- تابلو کانبان با جابجایی نرم کارت‌ها به کمک کتابخانه مدرن `@dnd-kit`.
- مراحل پایپ‌لاین: *لید جدید ← تماس اولیه ← واجد شرایط ← نیازسنجی ابعاد/طرح ← پیشنهاد فرش و قیمت ← مذاکره و پیش‌فاکتور ← منتظر تصمیم ← معامله موفق (Won) ← از دست رفته (Lost)*.

### ۵. موتور هوشمند تطابق و پیشنهاد فرش (Recommendation Engine)
- ارزیابی چندمعیاره ترجیحات مشتری با موجودی واقعی انبار.
- محاسبه درصد تطابق (۰ تا ۱۰۰٪) و اولویت‌بندی کالاهای آماده تحویل انبار.

### ۶. دفترچه اقساط و مدیریت سررسید چک‌ها (Installment Ledger)
- قید یکتایی ترکیبی `(orderId, installmentNumber)` در سطح پایگاه داده جهت جلوگیری قطعی از اقساط تکراری.
- صدور جدول اقساط با سررسیدهای ماهانه شمسی و ثبت سریال چک صیادی.
- کلید یکتای پرداخت (`idempotencyKey`) جهت جلوگیری از پرداخت‌های مضاعف.

### ۷. انبارداری و ردیابی گردش کالا (Inventory & Movement History)
- کنترل موجودی کل، رزرو فعال و فروخته‌شده به تفکیک SKU و ابعاد.
- محافظت کامل در برابر فروش بیش از موجودی (`Oversell Prevention`) و همزمانی فروش.
- ثبت اسناد ورود از بافندگی، خروج فروش (`SALE`)، رزرو و اصلاحیه انبارگردانی.

### ۸. فاکتور رسمی چاپ با استاندارد شرکتی (Printable Official Invoice)
- چاپ مستقیم پیش‌فاکتور و فاکتور نهایی همراه با مشخصات خریدار، فروشنده، اقلام، تخفیف، مهر و امضا.

### ۹. امنیت، سطوح دسترسی (RBAC) و لاگ وقایع (Audit Trail)
- نقش‌های کاربری: `ADMIN` (مدیر ارشد)، `SALES_MANAGER` (مدیر فروش)، `SALES_REP` (کارشناس فروش).
- نشست‌های امن رمزنگاری‌شده با کوکی‌های HttpOnly، ابطال آنی کاربران غیرفعال و هش پسورد `bcryptjs`.
- ثبت تمامی تغییرات حساس در لاگ امنیتی سیستم.

### ۱۰. گزارش‌های تحلیلی هوش تجاری (BI Reports)
- نمودارهای مدرن Recharts: روند فروش ماهانه، سهم کلکسیون‌ها، قیف تبدیل لید و نقشه تراکم تقاضای استان‌ها.

## 🚀 راهنمای راه‌اندازی و استقرار

### ۱. محیط توسعه (Development Setup)
```bash
# نصب وابستگی‌ها
npm install --legacy-peer-deps

# آماده‌سازی اولیه دیتابیس و داده‌های نمونه
npm run db:setup

# اجرای سرور توسعه
npm run dev
```

### ۲. محیط استقرار پروداکشن (Production Deployment)
در محیط عملیاتی پروداکشن، پایگاه داده با سیستم مایگریشن رسمی و ورژن‌بندی‌شده هدایت می‌شود:
```bash
# اعمال مایگریشن‌های دیتابیس به صورت ایمن
npx prisma migrate deploy

# تولید کلاینت پریزما
npx prisma generate

# بیلد نهایی برنامه
npm run build

# اجرای سرور پروداکشن
npm start
```
